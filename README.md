# QR Open

App Android quét / tạo mã QR và mở link nhanh. Nhẹ (~78 KB), đọc và tạo mã ngay trên máy, không gửi dữ liệu đi đâu.

## Tải về

**[⬇ Tải QR-Open.apk (bản mới nhất)](https://github.com/ht2602/qr-open/releases/latest/download/QR-Open.apk)**

Yêu cầu Android 8.0 trở lên. Mở link trên điện thoại, tải xong bấm vào tệp để cài.
Nếu máy báo chặn: cho phép "Cài ứng dụng không rõ nguồn" cho trình duyệt (hoặc trình quản lý tệp) đang dùng để tải.

SHA-256 của bản 1.0.0 (để kiểm tra tệp tải về nguyên vẹn):

```
5e01ed282b1e7f569d5b7de274285604e0f72bbdd05c47cb78a02d552d426ca5
```

## Tính năng
- Quét bằng camera hoặc chọn ảnh có mã QR; quét ra link thì tự mở (bật/tắt trong Cài đặt).
- Nhập link/văn bản để tạo mã QR hoặc mở thẳng; sao chép, chia sẻ, lưu ảnh mã.
- Giao diện sáng/tối (Theo máy / Sáng / Tối).
- Deeplink: `qropen://scan`, `qropen://image`, `qropen://open?url=<link>`, `qropen://make?text=<nội dung>`.
